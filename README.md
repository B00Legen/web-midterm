# Manga fan website
Midterm project for the `Web Technologies 1` course.
### Group Members
`Mukhammedali Bolegen`, `SE-2538`.
### Description
A simple manga website that is heavily inspired by [Mangalib](https://www.mangalib.me).
### List of features
- Travel between different pages.
- Navigation bar visible on all pages.
- Light and Dark mode toggle.
- Navigation bar always visible (position: sticky).
- Used flexbox on navigation bar.
- Used grid on main content.
- Table, form (todo).
- Hover, focus (1/2).
- Pseudo class used (:root) with variables.
### Technologies used
- Basic HTML
- Basic CSS
- Bootstrap CSS
